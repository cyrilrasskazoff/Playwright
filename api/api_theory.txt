GET
чтобы отправить GET запрос на нужный вам эндпоинт, используйте метод page.request.get() с указанием url.

POST
чтобы отправить POST запрос на нужный вам эндпоинт, используйте метод page.request.post()  c указанием url. Так-как POST
запрос имеет тело, то при использовании данного метода нужно указывать тип тела запроса в заголовке content-type

Тело запроса указывается параметром data, а заголовок запроса передается с помощью параметра headers.

Посмотреть содержание тела ответа можно с помощью трех методов:
response.text()
response.json()
response.body()
